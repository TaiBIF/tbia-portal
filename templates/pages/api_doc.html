{% trans 'API 基本說明' %}

{% trans 'TBIA 提供開放 API，讓使用者可以透過程式設計方式查詢與取得 TBIA 資料。本 API 為公開服務，對所有人開放，惟請注意：' %}

  • {% trans '本服務會進行部分資訊模糊化，以保護敏感物種。可取得未模糊化資料的限制型 API 僅適用於物種出現紀錄（Occurrence API），目前僅供 TBIA 夥伴單位申請使用；有需求之夥伴單位可來信聯絡 TBIA 秘書處' %} tbianoti@gmail.com
    • {% trans '模糊化精度依敏感層級（sensitiveCategory）而定，處理方式記載於 dataGeneralizations。' %}
    • {% trans 'decimalLatitude／decimalLongitude：公開 API 為模糊化後的坐標，限制型 API 為原始坐標。' %}
    • {% trans 'verbatimLatitude／verbatimLongitude：公開 API 中如該筆紀錄經模糊化處理，本欄位將轉為空值；限制型 API 為原始坐標。' %}
    • {% trans 'county／countyCode／municipality：公開 API 依模糊化後坐標推算，限制型 API 依原始坐標推算。' %}
  • {% trans '本 API 目的為供機器間自動處理，非供直接閱讀。' %}

{% trans '本 API 提供四種服務類型（各服務網址與參數請見下方各章節）：' %}

  • {% trans '物種出現紀錄 occurrence' %}{% trans '：提供 TBIA 收錄之物種出現紀錄查詢。本服務會進行部分資訊模糊化。' %}
  • {% trans '資料集 dataset' %}{% trans '：提供 TBIA 收錄資料集查詢。可用於了解各資料集之後設資料。' %}
  • {% trans '地圖 map' %}{% trans '：提供以網格聚合之物種出現點位統計，回傳 GeoJSON 格式。' %}
  • {% trans '夥伴單位 partner' %}{% trans '：提供 TBIA 夥伴單位查詢。可用於取得 tbiaPartnerID 與對應之單位名稱。' %}
